# Assets Required

This folder should contain Rive animation files (.riv):

## Required Files:
- `cat.riv` - Main pet cat with State Machine (idle, happy, sad, levelup)
- `habitspet.riv` - Habit tracking pet companion
- `muza-your-cat-companion.riv` - Muza cat variant

## State Machine Requirements:
Each .riv file should have:
- State Machine named "State Machine 1"
- Optional: "Chin hold" (bool) and "Forehead click" (trigger) inputs for interactivity

## Note:
Without these files, the app will display emoji fallbacks (🐱, 🌟).
Download free cat animations from https://rive.app or create custom ones.
